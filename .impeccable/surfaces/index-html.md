# Surface brief: index.html (portfolio home)

Scope: the single-page portfolio/CV at the repo root. Mode: Persuade. The visitor (a hiring manager or a scientific peer) decides whether Calvin is worth contacting and does so via LinkedIn, with GitHub as the second route.

Proof on the page: IMPRESSION (paper, code, web app), two publications, four talks, four generalised AstraZeneca work entries, a Bristol PhD and postdoc with a promotion. No invented metrics beyond PRODUCT.md.

## Direction contract

THESIS: The CV set as a labelled laboratory reagent: a light lab-bench ground carrying white label stock, ruled specification grids and catalogue numbers. It refuses the category default of a greeting headline, a "view my work" button and a grid of rounded project cards.

OWN-WORLD: Light warm-grey lab-bench ground (#c9c7bf to #e9e8e3) with a soft vertical highlight; sections stack like sheets of paper as you scroll. Near-white label panels (#fbfbf7) with 2px black rules and 1px hairline row rules. One cobalt band colour (#1f4fd1) for the label band, active atom and focus. Condensed heavy grotesk (Archivo, condensed width) in caps for names. Mono (JetBrains Mono) only for catalogue numbers, spec values and dates. Square corners everywhere. Buttons are solid black label blocks.

STORY: Who he is (graph ML for chemistry, now AstraZeneca) → the work as catalogue entries → experience as a certificate-of-analysis table → literature (papers and talks) → composition (skills) → contact.

FIRST VIEWPORT: Thin label-stock nav strip. One label fills the viewport inside equal 72px edges: the cobalt band on top; the left 55% holds "CALVIN YIU, PhD" huge, the title line, a three-row spec table and the LinkedIn + GitHub actions; the right holds an interactive skeletal molecule drawn on the label.

FORM: Reagent bottle label / supplier catalogue, #6 on the grounded list. seed:4d0dfbf059e30515. Raises: fixed slots with deliberate dashes (seven-segment); deep-linkable catalogue numbers (HyperCard); leader-line annotations on atoms (tensegrity); one shared scale and baseline (botanical). Signature interaction: hovering or focusing an atom pins a leader-line annotation with its illustrative predicted shift, the IMPRESSION mechanism shown in place.
